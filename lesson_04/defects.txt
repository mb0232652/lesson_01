Заголовок: "Метод capitalize отработывает некорректно регистр(ломает исходные данные)
Описание: Данный метод реализован так, принудительно меняет регистр всех букв на строчные, кроме первой.Кроме этого  даный метод не находит первую букву, если строка начинается с цифр, что протеворечит ТЗ, где сказано:"делает первую букву заглавной и возвращает этот же текст"(указания менять остфльные - нет)
Окружение:операционная система Windows 10
Язык:Python 3.15.0
Библиотека: pytest 9.2.0
Шаги воспроизведения:
1.Вызвать метод  capitalize("skyPro")
Ожидаемый результат: возвращает"SkyPro",меняет первую букву, остальные не трогает.
Фактический результат: возвратил "Skypro", т.е. буква "Р",которая в середине слова стала строчной
2.Вызвать метод  capitalize("SKYPRO") 
Ожидаемый результат: возвращает"SKYPRO",т.к. буквы уже все заглавные,т.е. ничего менять не надо.
Фактический результат: возвратил "SkyPro", т.е. сломался регистр остальных букв
3.Вызвать метод  capitalize("123abc") 
Ожидаемый результат: возвращает""123Аbc"",т.е. находит первую букву(как по ТЗ) и меняет её на заглавную.
Фактический результат: возвратил "123abc", т.е. метод не нашел первую букву, т.к. вначале стоят цифры
Итог:Все три теста упали по одной причине -метод capitalize-его использование
Серьёзность: Major
Приоритет:High

Библиотека: pytest 9.2.0
Шаги воспроизведения:
1.Вызвать метод contains с аргументом None, "S".
2.В консоле прочитать результат выполнения теста.
Ожидаемый результат: Метод возвращает False(в пустоте нет символов)
Фактический результат: Метод выдает ошибку AttributeError: 'NoneType' object has no attribute 'index'
Итог:Все три теста упали по одной причине -метод capitalize-его использование
